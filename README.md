###

Analyze transcriptomic datasets using Python and R.  
Perform differential gene expression, functional enrichment, pathway analysis, and biomarker discovery.  
Apply reproducible bioinformatics workflows to investigate disease mechanisms.

**Data Analytics**

Analyze and interpret complex datasets using SQL, Power BI, R, and Excel to generate evidence for research and decision-making.

**Clinical Research**

**Data Visualization & Scientific Communication**
